# Арена моделей: Мир vs RU — Telegram-бот для сравнения нейросетей

<img src="branding/avatar.jpg" alt="Арена моделей" width="120" align="right">

Telegram-бот [@ModelArenaRU_bot](https://t.me/ModelArenaRU_bot): один вопрос — три нейросети
одновременно. «Мировая» модель на выбор пользователя против российских **GigaChat** и
**YandexGPT**. Пользователь оценивает каждый ответ ⭐1–5, бот копит личный и общий рейтинг
моделей и лучшую модель по каждой теме. Работает 24/7 на Linux-сервере.

*Telegram bot that asks one question to three LLMs at once — a global model of your choice vs
Russian GigaChat and YandexGPT — with live progress, cost per answer, ratings and leaderboards.
Python · aiogram 3 · SQLite · direct GigaChat / YandexGPT REST APIs · OpenAI-compatible API.*

## Возможности

| Кнопка | Что делает |
|---|---|
| 🎲 Вопрос по теме | 10 тем (история, наука, технологии, финансы, право, математика…) — вопрос придумывает нейросеть |
| ✍️ Свой вопрос | любой вопрос до 500 знаков |
| ⚙️ Модель | выбор «мировой» модели: GPT-4o mini, DeepSeek V4 Flash, Gemini 3.1 Flash-Lite; флагманы (GPT-5.5, Claude Sonnet 5.5, Gemini 3.1 Pro) — 🔒 для будущей Pro-версии |
| 📊 Статистика | общий рейтинг, мой рейтинг, лучшая модель по каждой теме |

Во время раунда — живое табло: у каждой модели статус 🤔 думает → ✍️ пишет… (счётчик знаков) →
✅ готово за N с. Под каждым ответом — время, цена в рублях и кнопки оценки; после всех оценок —
итог раунда. Бесплатно — 10 вопросов в день.

## Решения, которые стоит отметить

- **Один интерфейс для трёх разных API.** `providers.ask(модель, вопрос)` возвращает текст,
  время, токены и цену — бот не знает, с каким поставщиком говорит. Новая модель = строка в `catalog.py`.
- **GigaChat — напрямую по REST, без SDK.** Authorization Key обменивается на токен доступа на
  30 минут, токен кэшируется и обновляется заранее. Серверы Сбера подписаны сертификатом
  Минцифры — он лежит в `certs/` и передаётся в TLS-контекст только для этих запросов.
- **YandexGPT — Foundation Models API** с API-ключом сервисного аккаунта и ID каталога.
- **Три ответа параллельно** (`asyncio.gather`), «мировая» модель — потоком (streaming), поэтому
  табло показывает, сколько уже написано.
- **Честная цена.** Стоимость каждого ответа считается по токенам и прайсу поставщика (₽ за 1 млн
  токенов, сверено с официальными тарифами) — сравнение не только по качеству, но и по деньгам.
- **Генератор вопросов под контролем.** Промпт ограничен общеизвестными фактами и типами
  вопросов, последние 15 вопросов темы передаются как «уже было» — без повторов и выдумок.
- **Секреты — только из окружения или файлов** (`*_FILE`), в коде и репозитории их нет.

## Стек

Python 3.10+ · [aiogram 3](https://docs.aiogram.dev/) · aiohttp · openai (ProxyAPI) · SQLite ·
GigaChat API · Yandex Foundation Models API · systemd.

## Структура

| Файл | Назначение |
|---|---|
| `bot.py` | Telegram-бот: темы, свой вопрос, раунд с живым табло, оценки, выбор модели, статистика, лимит |
| `providers.py` | подключение моделей: ProxyAPI (openai), GigaChat (OAuth-токен, сертификат), YandexGPT; генератор вопросов |
| `catalog.py` | каталог моделей с ценами, темы, дневной лимит |
| `storage.py` | SQLite: пользователи, раунды, ответы, оценки, рейтинги |
| `certs/` | корневой сертификат Russian Trusted Root CA (публичный, для HTTPS к GigaChat) |
| `tools/check_providers.py` | проверка подключений без Telegram: один вопрос → ответ, время, цена |
| `deploy/` | unit-файл systemd и зависимости для сервера |

## Запуск локально

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt     # Linux/macOS: .venv/bin/pip
# задать переменные из .env.example
.venv/Scripts/python tools/check_providers.py     # проверить ключи всех трёх поставщиков
.venv/Scripts/python bot.py
```

## Сервер

`deploy/model-arena-bot.service` — служба systemd под отдельным пользователем без прав root:
`Restart=always`, ограничение памяти 300 МБ, ключи читаются из файлов (`*_FILE`). Бот занимает
около 185 МБ памяти; раунд в базе ≈ 7 КБ. Журнал — до 1 МБ + 3 архива, старое удаляется само.
